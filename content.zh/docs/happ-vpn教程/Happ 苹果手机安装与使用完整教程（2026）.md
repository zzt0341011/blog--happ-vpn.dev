# Happ 苹果手机安装与使用完整教程

## 一、什么是 Happ？为什么需要美区 Apple ID？

**Happ**（全称 Happ - Proxy Utility）是一款基于 Xray 内核的免费代理客户端，支持 VLESS（Reality）、VMess、Trojan、Shadowsocks、Hysteria2 等主流协议。它本身不提供任何服务器节点，只是一个工具，需要你自己导入机场订阅链接才能使用。

由于很多国家 App Store 通常搜不到这款应用，所以需要使用**美区（或其他外区）Apple ID** 才能在 App Store 中下载。最常见的做法是临时使用共享的美区 Apple ID。

![happ-1001.jpg](https://happ-vpn.dev/img/happ-1001.jpg)

### 重要提醒（必读）

- 共享 Apple ID **只能**用于登录 App Store 下载应用。
- **绝对不要**在「设置 → 顶部 Apple ID / iCloud」中登录共享账号，否则可能触发“丢失模式”导致手机被远程锁定，只能刷机解决。
- 下载完成后请立即退出共享账号，切回自己的账号。
- 共享账号随时可能失效或被多人同时使用，建议下载完后尽快切换回自己的 ID。

## 二、准备工作

1. 一台 iPhone（建议 iOS 15 及以上）
2. 一个可用的美区共享 Apple ID（可在各类共享站、Telegram 频道或相关论坛获取，注意选择近期更新的账号）
3. 一个机场订阅（后面会说明如何购买）

## 五、日常使用小技巧

- 可在 Happ 内测试节点延迟（Ping），优先选择延迟低且稳定的节点
- 支持规则分流（可根据需要配置）
- 建议开启“开机启动”等实用功能（视版本而定）
- 订阅链接有更新时，在 Happ 中刷新订阅即可
- 如果节点全部失效，优先检查机场是否到期或订阅是否被重置

## 六、常见问题

**Q：共享 ID 登录后提示账号异常/需要验证？**  
A：换一个新的共享账号即可，共享号经常被多人使用导致被风控。

**Q：下载后找不到 Happ？**  
A：确认开发者是 Flyfrog LLC，避免下载到山寨应用。

**Q：连接后无法上网？**  
A：检查订阅是否有效、节点是否被墙、是否开启了正确的协议，或尝试切换其他节点。

**Q：可以长期使用共享 ID 吗？**  
A：不推荐。共享 ID 风险较高，长期使用建议自己注册一个美区 Apple ID（免费，只需邮箱和美国地址信息）。
